Codex 完全入门指南

给第一次接触 AI 编程工具的电脑小白 · 以官方资料为准

先记住：OpenAI Codex、CC Switch、Codex++、Watt Toolkit 和 DeepSeek 是不同的东西。本文会先分清它们，再决定是否需要安装。

目录

一、先认识这几个工具二、你该选哪条路三、安装官方 Codex四、使用 CC Switch五、使用 Codex++六、接入 DeepSeek 等兼容 API七、Watt Toolkit 只负责什么八、安全与第一次使用

一、先认识这几个工具

OpenAI Codex

OpenAI 的编程智能体/产品名称。入口可能是官方 CLI 或桌面应用。

CC Switch

统一管理多个 AI 编程 CLI 的供应商配置、本地路由、MCP、Skills、会话和用量。

Codex++

面向 OpenAI Codex / ChatGPT 桌面应用的外部启动器和管理工具。

Watt Toolkit

开源跨平台多功能游戏工具箱，原名 Steam++，不是 OpenAI 或 Codex 工具。

不要把 CC Switch 或 Codex++ 说成 OpenAI 官方组件，也不要把 Watt Toolkit 说成 OpenAI API 加速器。

二、你该选哪条路

只用官方 Codex

适合使用官方账号、官方登录和官方支持。直接按 OpenAI Codex 官方文档选择 CLI 或桌面入口。

需要切换多个供应商

选择 CC Switch。它是管理工具，本身不是模型，也不会自动赠送 API 额度。

使用桌面版 Codex 并想要图形管理

选择 Codex++。它需要官方 Codex / ChatGPT 桌面应用，并从自己的 Release 页面安装。

想用 DeepSeek

DeepSeek 是独立的模型/API。它在中国大陆通常可直连，但要通过明确支持自定义供应商的工具接入，不等于官方 Codex 原生自带 DeepSeek。

三、安装官方 Codex

官方安装方式会随版本更新，所以不要照抄旧博客中的命令。按下面做：

1

打开 OpenAI Codex 官方文档。

2

选择你的系统和入口：CLI 或桌面应用。

3

只使用官方页面提供的安装包或当前命令。若说明要求 Node.js，再从 Node.js 官网安装 LTS 版本。

4

第一次启动按官方登录流程授权。先在练习项目里使用，不要直接让它修改重要项目。

第一次对话建议这样说：

先不要修改文件。请阅读当前项目结构，用简单中文告诉我你看到了哪些文件，以及你准备怎么做。需要执行命令时先列出命令并等待我确认。

四、使用 CC Switch

CC Switch 官网将它定位为 AI 编程 CLI 统一管理工具，支持 Codex、Claude Code、Gemini CLI、OpenCode、OpenClaw、Hermes Agent 等。

1

从 ccswitch.io进入官网和安装入口。

2

安装并打开 CC Switch，在工具列表中选择你已经安装的 CLI。

3

在供应商页面添加自己的名称、协议、Base URL、模型和 API Key。字段以当前版本界面为准。

4

先使用测试功能确认连接，再切换供应商和启动 CLI。

CC Switch 不是中转站，也不提供模型额度。你仍需要官方账号或自己选择的 API 服务商账号。

五、使用 Codex++

Codex++ 官方 README 将它定义为 OpenAI Codex / ChatGPT 桌面应用的外部启动器与管理工具，不修改官方应用安装目录中的补丁文件。

下载安装

从 Codex++ Releases下载：

  • Windows：CodexPlusPlus-*-windows-x64-setup.exe
  • macOS Intel：CodexPlusPlus-*-macos-x64.dmg
  • macOS Apple Silicon：CodexPlusPlus-*-macos-arm64.dmg

安装后通常有“Codex++”和“Codex++ 管理工具”两个入口。先打开管理工具确认应用路径和运行状态，再配置供应商，最后从 Codex++ 入口启动。

供应商模式

  • 官方登录：使用 ChatGPT / Codex 官方账号。
  • 官方登录 + API：保留官方账号与插件入口，模型请求走兼容 API。
  • 纯 API：不依赖官方账号，使用自定义 Base URL 和 Key。
  • 聚合供应商：在多个普通 API 供应商之间路由。

具体字段必须在 Codex++ 管理工具中配置，不要复制旧版 JSON。官方 README 提到的本地数据位置包括 ~/.codex/config.toml、~/.codex/auth.json 和 ~/.codex-session-delete/，不要把这些文件上传到 GitHub。

六、接入 DeepSeek 等兼容 API

DeepSeek 是独立模型/API，在中国大陆通常可以直接访问。它不是 OpenAI Codex 本体。

1

在 DeepSeek 官方平台注册并创建 API Key。

2

阅读 DeepSeek 当前 API 文档，确认 Base URL、协议和模型名称。

3

在 CC Switch 或 Codex++ 中添加自定义供应商，填写服务商要求的字段。

4

使用工具内的测试功能验证，再启动 Codex 工作流。

本教程不提供未经对应项目 README 确认的命令、配置键名或配置文件路径。不同工具和版本的配置不能混用，看到网上示例时请回到对应项目的官方发布页核对。

七、Watt Toolkit 只负责什么

Watt Toolkit 官方 README 将它介绍为“开源跨平台的多功能游戏工具箱”，原名 Steam++，大部分功能需要安装 Steam。

  • 它不是 Codex 的安装前置条件。
  • 本文只把它作为下载 CC Switch 的可选 GitHub 辅助工具。
  • 它不是 OpenAI API 加速器。
  • 它不是 GPT 中转站，也不会提供模型额度。
  • 如需使用，只应以 Watt Toolkit 官方 README和软件界面为准。

八、安全与第一次使用

保护 API Key

  • 不要发到聊天群、截图、issue、README 或 Git 仓库。
  • 泄露后立即在供应商后台撤销并重建。
  • 中转服务能看到你发给它的请求，重要源码不要交给不信任的服务商。

先读后改

给 Codex 的第一条任务可以是：

请先不要修改任何文件。阅读当前项目，告诉我入口文件、主要目录和运行方式。如果需要安装依赖或执行命令，先说明用途并等待我确认。
